# 青幕视听分镜导演

本 Skill 在权威视频文案已经存在后工作。不得改写、合并或拆分文案里的时间段；一个文案标记严格对应一个结构化分镜。

## 逐镜导演卡

先在内部为每镜回答十四项，再压缩进 `image_prompt` 和 `video_prompt`：

1. 本镜推动剧情或人物变化的功能。
2. 地点、时段、天气与前中后景空间。
3. 出场人物的稳定身份锚点、服装、发型、左右位置和视线。
4. 核心物品的外观、持有者和位置。
5. 动作开始状态、过程、反应和结束状态。
6. 景别。
7. 构图与视觉重心。
8. 机位高度、角度和轴线。
9. 焦段与景深。
10. 相机运动、速度、方向，以及此时移动的戏剧动机。
11. 主光、辅光、轮廓光和实景光源；方向、软硬、色温、反差与阴影。
12. 主色、辅助色、材质与曝光。
13. 对白、环境声、动作音效、音乐状态和声音桥。
14. 入镜方式、剪辑点、下一镜衔接和需要避免的生成错误。

## 首帧与视频提示分工

`image_prompt` 是单一静态瞬间：以主体身份和第一帧动作姿态开头，然后写场景层次、景别、构图、机位、焦段、光线、色彩、画幅和连续性锚点。不能写推拉摇移、动作过程、声音或多个时刻。

`video_prompt` 从该首帧继续：重复人物、服装、场景和关键物品锚点；按时间顺序写一个连续动作及他人反应；说明环境运动；写有动机的单一主要运镜和必要的轻微机位调整；人物对白写清说话者、原句、自然语气、呼吸停顿、口型同步、微表情、对方反应与现场声；最后明确结束姿态和结束构图。结尾加入本镜最相关的禁止项，例如不变脸、不换装、不增加人物、不改变物品数量、不瞬移、不跳轴、不出现文字水印。

相机不因“画面更电影”而移动。推近用于压力或认知收紧；拉远用于暴露孤立或后果；横移用于关系变化；跟拍用于追随明确行动；环绕用于权力或认知翻转；固定机位用于压迫、观察或让表演承担张力。

## 剪辑与连续性

- 优先使用动作接切、视线接切、构图匹配、声音桥或因果反应。每镜必须给下一镜留下清楚的结束画面。
- 保持 180 度轴线、人物左右位置、动作方向、视线、服装、物品手持关系、天气、色温和光源方向连续。需要越轴时先用中性机位建立。
- 相邻镜头改变景别或角度应有叙事理由，避免连续两个几乎相同的构图。
- 对话使用主讲者镜头、对方反应镜头和必要的双人关系镜头；同一分镜最多一条人物自然台词。原句保存到 `dialogue`，真实角色 ID 保存到 `speaker_id`，并将该角色置于 `asset_ids` 第一项；`dialogue_start`、`dialogue_end` 用镜内秒数标出实际开口区间，video_prompt 用相同秒数安排台词、同步口型和现场原声，字幕只在该区间显示。不调用旁白 TTS，没有对白时再按画面重要性排序。
- `narration` 只用于少量画外旁白；旁白镜头在视频提示中明确“无人物对白，保留自然环境声，旁白后期混入”。同一镜不同时填写 `dialogue` 与 `narration`。

## 生成前检查

每镜必须同时拥有环境压力、一个可见的微动作、一个声音或视觉母题；相机运动有明确动机；空间关系能读懂；人物、场景、物品、动作和风格五类锚点完整；提示词在本镜时长内可执行。失败项先修正再调用模型。
