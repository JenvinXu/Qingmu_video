# 青幕短剧情编剧

本 Skill 只负责短剧情的剧作设计。媒体生成、资产 ID、剪辑和导出交给 `video-director`；镜头语言和模型提示交给 `visual-video`。

## 一分钟短片的压缩流程

先把用户的一句话变成一个可以通过人物选择证明的故事，不用旁白解释主题。

1. 定义主角此刻可见的目标、阻力、失败代价，以及妨碍其行动的错误信念或缺陷。
2. 用一句前提表达“什么样的人，因为做了什么，在压力下得到什么结果”。
3. 设计五个递进节拍：抓人动作；诱发事件与选择；阻力升级；不可逆转的高潮决定；有视觉回响的结果。
4. 主要人物控制在 2–3 名。每人都要有不同的行动方式、说话节奏和利益；对手不一定是坏人，但必须有同样明确且相斥的目标。
5. 地点控制在 1–2 个，核心物品控制在 1–3 件。场景和物品必须参与冲突、选择或转折，不能只做装饰。

## 对白

- 对白是人物采取的行动。每句都应试图逼迫、隐瞒、试探、拒绝、交换或挽回，并引起下一句或下一个动作。
- 让表面意思与真实意图有距离，删除人物双方都知道的说明性信息。
- 角色遮住名字后，仍应能从用词、句长和态度分辨说话者。
- 一分钟短片以短句和停顿为主。一个生成分镜最多安排一名角色说一条能自然完成的台词；对话交锋使用正反打或反应镜头拆开。
- 短剧以视频中的人物自然对白为主。人物说出的原句保存到 `dialogue`，说话角色保存到 `speaker_id`；为对白规划镜内开口和结束秒数，分别保存到 `dialogue_start`、`dialogue_end`，对白前后的动作留白不显示字幕。视频模型负责在同一秒数内生成语气、呼吸、口型和现场声，不为人物台词另做旁白配音。
- `narration` 只保存明确的画外旁白，不含角色名、括号表演提示和引号。旁白最多占总分镜的 20%，只用于时间跳跃、背景事实或短促内心信息，不逐镜解说。
- 同一分镜不要同时安排人物对白与旁白。口播项目另行处理，每个片段仍必须有 `narration`。

## 保存到青幕

`synopsis` 保存紧凑的制作设计，使用以下顺序：主题与前提、Logline、人物、场景、关键物品、五段剧情节拍、视听母题、结局画面。人物写清可见外貌锚点、服装、目标、缺陷、关系和声音气质；场景写清空间布局、时间、天气和实景光源；物品写清外观、持有关系和剧情功能。

`script` 只能使用软件要求的连续时间段与分镜编号。每个冒号后的本镜文案同时写清可拍动作和必要对白；人物台词标为“角色名说：‘原句’”，画外旁白标为“旁白：‘原句’”。时间必须从 0 连续到目标时长，并严格采用软件给出的逐镜时长方案。不要把制作设计、标题、Markdown 或解释混入 `script`。

保存前检查：主角主动做了不可逆选择；冲突至少升级一次；高潮由人物选择造成；结局回应开头；人物、服装、物品、空间方向和时间连续；每句对白都改变当前局面。
