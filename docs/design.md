# 青幕工作台视觉与交互

主体是个人创作者的本地视频工作台。口播的首要任务是一段话成片；短剧的首要任务是把故事变成可以逐镜制作的时间线。

颜色：雾绿 #F7FAF7、纸白 #FFFFFF、嫩绿 #D9EDDE、松绿 #286047、墨绿 #233C30、石灰 #718076。中文正文用 Microsoft YaHei / PingFang SC，标题用 Segoe UI Variable，时间码用 Cascadia Code / Consolas。

布局：180px 侧栏 + 自适应工作区。首页以真实封面作品卡片从左到右排列，删除必须确认。短剧上方是五个实际流程按钮：我的想法、视频文案、资产配置、分镜设置、视频制作。默认视频制作页使用左侧实时预览、右侧逐分镜参数、底部按时长占位的分镜时间线。整片预览只播放已有视频，并跳过空分镜。分镜卡片显示画面与对白文案；设置区内部滚动。口播采用六个独立页面：我的想法、口播文案、画面设置、画面制作、声音字幕、视频合成，完成标记来自实际项目状态；画面、配音、合成页使用底部片段时间线与左预览/右设置。生成和补齐按钮仅操作当前阶段，用户可切换片段控制媒体与声音。

界面采用留白、轻分隔线和真实素材缩略图，移除重复标题、说明卡片、流程宣传、建议按钮和模拟波形。模型设置只有一组保存按钮，视频参数、文案与素材来源按需展开。运行记录保留真实状态、用量、错误与验收证据。动作使用 140–220ms 过渡，尊重 reduced-motion；键盘焦点可见。
